What We Built

A six-capability prototype that covers the full lifecycle: intake → analysis → filing → monitoring → prevention.

📋 Risk Register

41 flags across 13 contracts, scored L×I (Likelihood × Impact). Filter by severity, HEROC category, status, source.

🤖 Smart Filing

Upload → AI classifies → auto-files to HEROC folder tree. No manual sorting. Real on-disk storage.

🔗 Cross-Reference

Tracks document dependencies. 5-step workflow: Detected → Acknowledged → Fixing → Verified → Closed.

📅 Deadline Tracking

Expiry + renewal notice deadlines. Timeline visualization. Urgency color-coding (expired / critical / warning / ok).

💡 Prevention Insights

Scans ALL monitored docs, detects systemic patterns (same issue in 3+ contracts), generates prioritized prevention playbook.

🏥 Department View

Filter by any of 22 Southlake departments. See exactly which contracts and flags belong to each team.

Prevention, Not Just Detection

The Insights engine goes beyond "this contract has a problem" to "here's the process gap causing 7 problems."

Systemic Pattern Detection

Scans all 41 flags, groups by field. When 3+ contracts share the same gap → it's a process failure, not a document error.

CRITICAL signatories — 7 flags · 7 contracts
HIGH breach_notification — 4 flags · 4 contracts
HIGH governing_law — 3 flags · 3 contracts

Prevention Playbook

For each pattern, generates an actionable recommendation targeting the control, not the document.

① signatories → "Implement pre-execution dual-signature verification gate"
② breach_notification → "Standardize to 24h (PHIPA s.33(3))"
③ governing_law → "Enforce Ontario law in all templates"
Impact: Fixing top 3 patterns eliminates 14 of 41 flags (34%). Portfolio risk score drops from 14.2 → 8.7.

How It Works

Each cross-reference shows Before (current text in target doc) vs After (required by source doc). A wizard guides the user through all 5 steps in one session — with human verification at each stage.
